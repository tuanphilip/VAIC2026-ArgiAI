# 1.3 Đặc tả API (API Specifications) - ArgiAI

Tài liệu này đặc tả chi tiết giao diện lập trình ứng dụng (API Endpoints) của hệ thống ArgiAI, giúp Frontend và Backend đồng bộ giao thức truyền tải dữ liệu.

- **Base URL**: `/api/v1`
- **Định dạng dữ liệu**: `application/json` (trừ endpoint tải ảnh lên sử dụng `multipart/form-data`)
- **Xác thực**: Sử dụng **JWT (JSON Web Token)** trong Header: `Authorization: Bearer <token>`

---

## 1. Nhóm API Xác thực (Authentication API)

### 1.1. Đăng ký tài khoản (`POST /auth/register`)
Đăng ký tài khoản mới cho nông dân hoặc cán bộ.

*   **Request Body**:
    ```json
    {
      "username": "nongdan_dienbien",
      "password": "SecurePassword123",
      "email": "nongdan@gmail.com",
      "full_name": "Nguyễn Văn A",
      "role": "farmer"
    }
    ```
*   **Response (201 Created)**:
    ```json
    {
      "status": "success",
      "message": "User registered successfully",
      "data": {
        "user_id": "a6d9b62c-87d3-4f9e-a89c-d8b5c92e76f9",
        "username": "nongdan_dienbien",
        "full_name": "Nguyễn Văn A",
        "role": "farmer"
      }
    }
    ```

### 1.2. Đăng nhập (`POST /auth/login`)
Đăng nhập để nhận Token xác thực.

*   **Request Body**:
    ```json
    {
      "username": "nongdan_dienbien",
      "password": "SecurePassword123"
    }
    ```
*   **Response (200 OK)**:
    ```json
    {
      "status": "success",
      "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "token_type": "bearer",
      "user": {
        "user_id": "a6d9b62c-87d3-4f9e-a89c-d8b5c92e76f9",
        "full_name": "Nguyễn Văn A",
        "role": "farmer"
      }
    }
    ```

## 3. Nhóm API Phát hiện dịch bệnh (Disease Detection API)

### 3.1. Nhận diện bệnh cây qua ảnh (`POST /diseases/detect`)
Gửi hình ảnh lá hoặc thân cây lên để AI chẩn đoán.

*   **Headers**: `Authorization: Bearer <token>`
*   **Request Body (multipart/form-data)**:
    - `image`: [File ảnh nhị phân]
    - `plot_id`: `A1` (optional, để liên kết với thửa đất)
*   **Response (200 OK)**:
    ```json
    {
      "status": "success",
      "data": {
        "disease_log_id": "1",
        "detected_disease": "Đạo ôn lúa (Rice Blast)",
        "confidence": 0.945,
        "severity": "Cao",
        "treatment_measures": "Ngừng bón phân đạm ngay lập tức. Giữ mức nước ruộng ổn định 3-5cm. Sử dụng dịch tỏi hoặc đồng nano để xử lý.",
        "image_url": "https://images.unsplash.com/photo-1574323347407-f5e1ad6d020b?auto=format&fit=crop&w=400&q=80"
      }
    }
    ```

### 3.2. Cán bộ cập nhật trạng thái dập dịch (`PUT /diseases/logs/{id}/status`)
Cập nhật trạng thái ổ dịch (Active sang Resolved) và ghi chú thực tế.

*   **Headers**: `Authorization: Bearer <token>`
*   **Request Body**:
    ```json
    {
      "status": "resolved",
      "official_notes": "Đã phun bổ sung đợt chế phẩm sinh học BT và kiểm soát hoàn toàn ổ dịch đạo ôn tại thung lũng."
    }
    ```
*   **Response (200 OK)**:
    ```json
    {
      "status": "success",
      "message": "Disease log status updated successfully",
      "disease_log_id": "1"
    }
    ```

## 4. Nhóm API Dự báo năng suất (Yield Forecast API)

### 4.1. Thực hiện dự báo sản lượng (`POST /yield/predict`)
Yêu cầu hệ thống tính toán năng suất và gợi ý lịch thu hoạch qua nhiệt tích lũy GDD.

*   **Headers**: `Authorization: Bearer <token>`
*   **Request Body**:
    ```json
    {
      "plot_id": "A1"
    }
    ```
*   **Response (200 OK)**:
    ```json
    {
      "status": "success",
      "data": {
        "forecast_id": "1001",
        "plot_id": "A1",
        "forecasted_yield_tons": 9.25,
        "confidence_score": 0.88,
        "optimal_harvest_start": "2026-09-10",
        "optimal_harvest_end": "2026-09-17",
        "weather_advisory": "Dự báo thời tiết tuần thu hoạch khô ráo, tích lũy nhiệt độ GDD đạt 1250°C ngày, thuận lợi cho việc gặt hái lúa Seng Cù."
      }
    }
    ```

## 5. Nhóm API Giá thị trường & Cảnh báo (Market Price & Alerts API)

### 5.1. Lấy biến động giá nông sản (`GET /market/prices`)
Lấy dữ liệu chuỗi thời gian giá của một loại cây trồng và phân tích xu hướng (SMA/ROC).

*   **Parameters**:
    - `crop_id`: `Robusta` (Không bắt buộc)
    - `days`: `30` (Mặc định lấy lịch sử 30 ngày qua)
*   **Response (200 OK)**:
    ```json
    {
      "crop_name": "Cà phê Robusta Mường Ảng",
      "currency": "VND/kg",
      "history": [
        { "date": "2026-07-15", "price": 84000, "source": "Sở Công Thương Điện Biên" },
        { "date": "2026-07-16", "price": 84800, "source": "Sở Công Thương Điện Biên" },
        { "date": "2026-07-17", "price": 86000, "source": "Sở Công Thương Điện Biên" }
      ],
      "recommendation": "Đường SMA-7 đã cắt lên trên đường SMA-30 (Golden Cross). Tốc độ trượt giá ROC tăng mạnh 1.4% hôm nay. Khuyến nghị: Giữ hàng chờ đạt đỉnh giá mục tiêu."
    }
    ```

### 5.2. Cán bộ thêm giá mới cập nhật (`POST /market/prices`)
Cập nhật bảng giá thu mua nông sản hôm nay.

*   **Headers**: `Authorization: Bearer <token>`
*   **Request Body**:
    ```json
    {
      "crop_name": "Hồ tiêu Phú Quốc",
      "price": 145000,
      "unit": "kg",
      "change": 0.0,
      "status": "flat"
    }
    ```
*   **Response (201 Created)**:
    ```json
    {
      "status": "success",
      "message": "Market price recorded successfully"
    }
    ```

### 5.3. Cán bộ xóa dòng giá nông sản (`DELETE /market/prices/{id}`)
*   **Headers**: `Authorization: Bearer <token>`
*   **Response (200 OK)**:
    ```json
    {
      "status": "success",
      "message": "Market price deleted successfully"
    }
    ```

### 5.4. Đăng ký cấu hình nhận cảnh báo giá (`POST /market/alerts`)
Nông dân cài đặt nhận cảnh báo qua tin nhắn SMS/Zalo khi giá thay đổi chạm ngưỡng mục tiêu.

*   **Headers**: `Authorization: Bearer <token>`
*   **Request Body**:
    ```json
    {
      "crop_name": "Cà phê Robusta Mường Ảng",
      "target_price": 90000
    }
    ```
*   **Response (201 Created)**:
    ```json
    {
      "status": "success",
      "message": "Price alert configured successfully"
    }
    ```
