# 1.3 Đặc tả API (API Specifications) - ArgiAI

Tài liệu này đặc tả chi tiết giao diện lập trình ứng dụng (API Endpoints) của hệ thống ArgiAI, giúp Frontend và Backend đồng bộ giao thức truyền tải dữ liệu.

- **Base URL**: `/api/v1`
- **Định dạng dữ liệu**: `application/json` (trừ endpoint tải ảnh lên sử dụng `multipart/form-data`)
- **Xác thực**: Sử dụng **JWT (JSON Web Token)** trong Header: `Authorization: Bearer <token>`

---

## 1. Nhóm API Xác thực (Authentication API)

### 1.1. Đăng ký tài khoản (`POST /auth/register`)
Đăng ký tài khoản mới cho nông dân hoặc cán bộ.

*   **Request Body**:
    ```json
    {
      "username": "nongdan_dienbien",
      "password": "SecurePassword123",
      "email": "nongdan@gmail.com",
      "full_name": "Nguyễn Văn A",
      "role": "farmer"
    }
    ```
*   **Response (201 Created)**:
    ```json
    {
      "status": "success",
      "message": "User registered successfully",
      "data": {
        "user_id": "a6d9b62c-87d3-4f9e-a89c-d8b5c92e76f9",
        "username": "nongdan_dienbien",
        "full_name": "Nguyễn Văn A",
        "role": "farmer"
      }
    }
    ```

### 1.2. Đăng nhập (`POST /auth/login`)
Đăng nhập để nhận Token xác thực.

*   **Request Body**:
    ```json
    {
      "username": "nongdan_dienbien",
      "password": "SecurePassword123"
    }
    ```
*   **Response (200 OK)**:
    ```json
    {
      "status": "success",
      "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "token_type": "bearer",
      "user": {
        "user_id": "a6d9b62c-87d3-4f9e-a89c-d8b5c92e76f9",
        "full_name": "Nguyễn Văn A",
        "role": "farmer"
      }
    }
    ```

## 2. Nhóm API Quản lý Khu đất canh tác (Plots API)

### 2.1. Lấy danh sách mảnh đất (`GET /plots`)
*   **Headers**: `Authorization: Bearer <token>`
*   **Response (200 OK)**:
    ```json
    [
      {
        "plot_id": "5f6e8d1a-4b9c-4d3e-8f2a-1c7b8d9e0f1a",
        "crop_name": "Lúa Điện Biên",
        "crop_variety": "Seng Cù",
        "area_hectares": 1.5,
        "seeding_date": "2026-05-10",
        "status": "growing",
        "location": {
          "lat": 21.3853,
          "lng": 103.0214
        }
      }
    ]
    ```

### 2.2. Khởi tạo mảnh đất mới (`POST /plots`)
*   **Headers**: `Authorization: Bearer <token>`
*   **Request Body**:
    ```json
    {
      "crop_id": "8c7b8d9e-0f1a-5f6e-8d1a-4b9c4d3e8f2a",
      "area_hectares": 2.3,
      "seeding_date": "2026-06-15",
      "location_lat": 21.4012,
      "location_lng": 103.0156
    }
    ```
*   **Response (201 Created)**:
    ```json
    {
      "status": "success",
      "message": "Plot created successfully",
      "plot_id": "b2c9e7f4-d5a6-4b8c-9d0e-1f2a3b4c5d6e"
    }
    ```

## 3. Nhóm API Phát hiện dịch bệnh (Disease Detection API)

### 3.1. Nhận diện bệnh cây qua ảnh (`POST /diseases/detect`)
Gửi hình ảnh lá hoặc thân cây lên để AI chẩn đoán.

*   **Headers**: `Authorization: Bearer <token>`
*   **Request Body (multipart/form-data)**:
    - `image`: [File ảnh nhị phân]
    - `plot_id`: `5f6e8d1a-4b9c-4d3e-8f2a-1c7b8d9e0f1a` (optional, để liên kết với mảnh đất)
*   **Response (200 OK)**:
    ```json
    {
      "status": "success",
      "data": {
        "disease_log_id": "7d9e8f2a-1c7b-8d9e-0f1a-5f6e8d1a4b9c",
        "detected_disease": "Đạo ôn lúa (Rice Blast)",
        "confidence": 0.942,
        "severity": "Medium",
        "treatment_measures": "1. Ngắt bỏ lá bệnh và tiêu hủy sạch.\n2. Tránh bón thêm phân đạm.\n3. Phun các loại thuốc đặc trị đạo ôn như Tricyclazole hoặc Fuji-One theo liều lượng khuyến nghị.",
        "image_url": "https://storage.argiai.vn/uploads/disease_logs/20260717_001.jpg"
      }
    }
    ```

## 4. Nhóm API Dự báo năng suất (Yield Forecast API)

### 4.1. Thực hiện dự báo sản lượng (`POST /yield/predict`)
Yêu cầu hệ thống tính toán năng suất và gợi ý lịch thu hoạch.

*   **Headers**: `Authorization: Bearer <token>`
*   **Request Body**:
    ```json
    {
      "plot_id": "5f6e8d1a-4b9c-4d3e-8f2a-1c7b8d9e0f1a"
    }
    ```
*   **Response (200 OK)**:
    ```json
    {
      "status": "success",
      "data": {
        "forecast_id": "3d9e8f2a-1c7b-8d9e-0f1a-5f6e8d1a4b9c",
        "plot_id": "5f6e8d1a-4b9c-4d3e-8f2a-1c7b8d9e0f1a",
        "forecasted_yield_tons": 9.25,
        "confidence_score": 0.88,
        "optimal_harvest_start": "2026-09-10",
        "optimal_harvest_end": "2026-09-17",
        "weather_advisory": "Dự báo thời tiết tuần thu hoạch khô ráo, thuận lợi cho việc phơi sấy gạo Điện Biên. Hãy theo dõi độ chín hạt đạt 85-90% để tiến hành gặt hái."
      }
    }
    ```

## 5. Nhóm API Giá thị trường (Market Price API)

### 5.1. Lấy biến động giá nông sản (`GET /market/prices`)
Lấy dữ liệu chuỗi thời gian giá của một loại cây trồng cụ thể.

*   **Parameters**:
    - `crop_id`: `8c7b8d9e-0f1a-5f6e-8d1a-4b9c4d3e8f2a` (Không bắt buộc, nếu không truyền sẽ trả về tất cả)
    - `days`: `30` (Mặc định lấy lịch sử 30 ngày qua)
*   **Response (200 OK)**:
    ```json
    {
      "crop_name": "Lúa Điện Biên (Seng Cù)",
      "currency": "VND/kg",
      "history": [
        { "date": "2026-07-15", "price": 18200, "source": "Sở Công Thương Điện Biên" },
        { "date": "2026-07-16", "price": 18300, "source": "Sở Công Thương Điện Biên" },
        { "date": "2026-07-17", "price": 18500, "source": "Sở Công Thương Điện Biên" }
      ],
      "recommendation": "Giá đang có xu hướng tăng nhẹ 1.6% trong tuần qua do nhu cầu tăng cao. Khuyến nghị: Giữ hàng hoặc chuẩn bị bán nếu đạt giá mục tiêu."
    }
    ```
