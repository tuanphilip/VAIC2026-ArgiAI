# 1.6 Hướng dẫn Cấu trúc Thư mục Code (Codebase Structure) - ArgiAI

Tài liệu này định nghĩa cấu trúc thư mục tiêu chuẩn của toàn bộ dự án ArgiAI (theo mô hình Monorepo hoặc chia Module rõ ràng), giúp AI biết chính xác vị trí cần đọc/ghi file khi thực hiện lập trình các chức năng.

---

## 1. Cây Thư mục Tổng quan (Root Structure)

```text
VAIC2026-ArgiAI/
├── docs/                 # Tài liệu phân tích, đặc tả thiết kế hệ thống
├── backend/              # Mã nguồn Backend API (Python - FastAPI)
├── frontend/             # Mã nguồn Frontend Dashboard & Mobile View (React/Vite)
├── ai-services/          # Mã nguồn huấn luyện và phục vụ mô hình AI (PyTorch/YOLO/XGBoost)
├── database/             # Script khởi tạo database, schema migrations & seed dữ liệu
├── tests/                # Bộ kiểm thử tự động (Unit test, Integration test)
├── .gitignore            # File bỏ qua các thư mục không cần commit lên Git
├── README.md             # Hướng dẫn chạy dự án nhanh
└── package.json          # Quản lý script khởi chạy toàn hệ thống (nếu dùng npm/yarn)
```

---

## 2. Đặc tả chi tiết từng Module

### 2.1. Backend Module (`/backend`)
Sử dụng cấu trúc phân tầng tiêu chuẩn của ứng dụng Python FastAPI.

```text
backend/
├── app/
│   ├── core/             # Cấu hình hệ thống (config, security, JWT)
│   ├── database/         # Kết nối DB, định nghĩa Base Model cho SQLAlchemy/SQLModel
│   ├── models/           # Định nghĩa các SQLAlchemy Model (ánh xạ bảng DB)
│   ├── schemas/          # Pydantic Schemas định nghĩa cấu trúc dữ liệu API (Request/Response)
│   ├── crud/             # Các hàm truy vấn, tương tác trực tiếp với cơ sở dữ liệu
│   ├── routes/           # Định nghĩa các API endpoint (Auth, Plots, Disease, Yield, Prices)
│   ├── services/         # Logic nghiệp vụ phức tạp (gọi AI service, kết nối Weather API)
│   └── main.py           # File khởi chạy ứng dụng chính
├── requirements.txt      # Quản lý các thư viện Backend Python cần cài đặt
└── Dockerfile            # Hướng dẫn đóng gói container Backend
```

### 2.2. Frontend Module (`/frontend`)
Sử dụng **Vite + React (TypeScript)** để xây dựng giao diện tối ưu tốc độ.

```text
frontend/
├── public/               # Các tài nguyên tĩnh (logo, biểu tượng)
├── src/
│   ├── assets/           # Hình ảnh, file CSS toàn cục (index.css định nghĩa thiết kế hệ thống)
│   ├── components/       # Các component UI dùng chung (Button, Table, Card, Chart, Sidebar)
│   ├── context/          # Quản lý trạng thái toàn cục (AuthContext, ThemeContext)
│   ├── hooks/            # Các Custom Hooks tiện ích (useFetch, useAuth)
│   ├── pages/            # Các trang giao diện chính:
│   │   ├── Login.tsx     # Đăng nhập
│   │   ├── Dashboard/    # Dashboard quản trị cho cán bộ
│   │   ├── Disease/      # Trang chụp ảnh nhận diện bệnh
│   │   ├── Plots/        # Trang quản lý khu đất & dự báo
│   │   └── Prices/       # Trang đồ thị theo dõi giá
│   ├── services/         # File cấu hình Axios/Fetch để gọi API lên Backend
│   ├── App.tsx           # Quản lý định tuyến (Routing) chính
│   └── main.tsx          # Điểm khởi chạy React
├── package.json          # Quản lý dependencies của Frontend
├── vite.config.ts        # Cấu hình Vite
└── Dockerfile            # Hướng dẫn đóng gói container Frontend
```

### 2.3. AI Services Module (`/ai-services`)
Nơi chứa các mã nguồn xử lý mô hình học máy, bao gồm tiền xử lý ảnh và chạy suy diễn (inference).

```text
ai-services/
├── weights/              # Lưu trữ file trọng số mô hình đã huấn luyện (.pt, .onnx, .bin)
├── models/               # Định nghĩa kiến trúc mạng thần kinh & giải thuật dự báo
│   ├── disease_classifier.py  # Load YOLOv8/EfficientNet để suy diễn ảnh bệnh
│   └── yield_predictor.py     # Load mô hình XGBoost để dự báo năng suất
├── utils/                # Hàm phụ trợ (tiền xử lý ảnh, tính toán chỉ số GDD)
├── app.py                # Service API siêu nhẹ (gRPC hoặc FastAPI nội bộ) chạy mô hình AI
├── requirements.txt      # Thư viện AI (torch, torchvision, xgboost, opencv-python)
└── Dockerfile            # Cấu hình container chạy AI trên môi trường hỗ trợ GPU/CPU
```

## 3. Quy trình Đóng góp Mã nguồn & Tương tác của AI
Khi AI nhận nhiệm vụ lập trình một chức năng mới:
1. **Bước 1**: Đọc [1.2 Thiết kế Cơ sở Dữ liệu.md](file:///d:/Github/VAIC2026-ArgiAI/docs/1.2%20Thi%E1%BA%BFt%20k%E1%BA%BF%20C%C6%A1%20s%E1%BB%9F%20D%E1%BB%AF%20li%E1%BB%87u.md) để viết/cập nhật SQL migrations tại `/database`.
2. **Bước 2**: Đọc [1.3 Đặc tả API.md](file:///d:/Github/VAIC2026-ArgiAI/docs/1.3%20%C4%90%E1%BA%B7c%20t%E1%BA%A3%20API.md) để viết Route, Schema và Service tương ứng trong `/backend/app`.
3. **Bước 3**: Viết logic xử lý AI (nếu có) tương ứng trong `/ai-services`.
4. **Bước 4**: Triển khai giao diện người dùng tương ứng trong `/frontend/src` đúng cấu trúc thư mục được chỉ định.
5. **Bước 5**: Viết unit test trong `/tests` để kiểm thử độ chính xác của API và luồng logic.
